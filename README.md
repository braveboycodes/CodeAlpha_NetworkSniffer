# 🔍 CodeAlpha_NetworkSniffer

## 🛠 Project: Basic Network Sniffer  
**Domain:** Cybersecurity

---

## 📖 About This Project

This is my **second project** during the **CodeAlpha Internship**, and I decided to go with something practical and core to cybersecurity – **packet sniffing**.

Basically, this tool captures live network traffic using Python and Scapy. It shows you:

- 🔹 Source IP
- 🔹 Destination IP
- 🔹 Protocol being used (TCP, UDP, ICMP)

It's a beginner-friendly sniffer, useful for understanding how data travels through networks and how attackers or defenders can analyze that traffic.

---

## 💡 What I Learned

- How packet sniffers actually work behind the scenes  
- Understanding IP packets and protocols  
- Using **Scapy** to inspect network traffic in real-time  
- Working with tools like **Npcap** to access network layers

---

## 🧰 Tools & Tech

- Python 3  
- Scapy (Python networking library)  
- Npcap (for packet capture on Windows)  
- VS Code
